KIOSK / מדריך התקנה

מסך אחד. בשליטה שלך.

ממשק בסיסי או אתר במסך מלא, עם הגדרות ויציאה שמוגנות ב־PIN אישי.

חשוב לדעת לפני שמתחילים

התקנת APK לבדה אינה נועלת את Android. נעילה מלאה מחייבת הקצאת Device Owner פעם אחת דרך מחשב. אין PIN ברירת מחדל. גבה את המידע בטאבלט ואת ה־PIN שתבחר.

1. מכינים את הטאבלט

  1. המכשיר צריך להיות ללא חשבונות Google / Samsung, משתמשים נוספים או ניהול ארגוני קיים. אם ההקצאה נכשלת, ייתכן שנדרש איפוס מפעל ידני אחרי גיבוי. הסקריפט אינו מאפס את המכשיר.
  2. חבר ל־Wi-Fi. אל תגדיר נעילת מסך של Android, כדי שהקיוסק ייפתח לאחר אתחול ללא המתנה לקוד המכשיר.
  3. בהגדרות: אודות הטאבלט ← פרטי תוכנה ← הקש 7 פעמים על מספר Build. באפשרויות למפתחים הפעל ניפוי באגים ב־USB.
  4. חבר למחשב בכבל USB שמיועד גם להעברת נתונים, ואשר בטאבלט את הרשאת המחשב.

2. מתקינים מהמחשב

  1. חלץ את כל חבילת Kiosk-Windows-Setup-1.2.0.zip.
  2. הפעל Install-Kiosk.cmd. בדוק את דגם המכשיר והקלד INSTALL.
  3. ודא שהפקודה להקצאת Device Owner הצליחה. אם Windows מונע הרצת הסקריפט, פתח PowerShell בתיקייה והרץ ידנית:
.\platform-tools\adb.exe devices
.\platform-tools\adb.exe install -r .\Kiosk-1.2.0.apk
.\platform-tools\adb.exe shell dpm set-device-owner il.co.kiosk/.KioskAdminReceiver
.\platform-tools\adb.exe shell am start -n il.co.kiosk/.MainActivity

אם הטאבלט אינו מזוהה, בדוק כבל, הרשאת USB ואת דרייבר Samsung הרשמי. אם הקצאת הניהול נכשלת, קרא את הסיבה בפלט; עצם התקנת האפליקציה אינה הוכחה שהנעילה פעילה.

3. בוחרים תוכן ומפעילים

  1. צור PIN אישי בן 6–12 ספרות ואמת אותו. שמור את הקוד במקום בטוח; אין קוד שחזור.
  2. בחר בממשק פנימי (כותרת, הודעה ושעון), או באתר עם כתובת https://.
  3. ודא שמופיע Device Owner פעיל. לחץ שמירה והפעלת הקיוסק ואשר את הנעילה.

ההפעלה חוסמת את הבית, היישומים האחרונים, ההתראות ו־USB debugging. מכאן ואילך הגישה לניהול היא בלחיצה על ⋮ בפינה הימנית העליונה, בחירת הגדרות הקיוסק והזנת PIN. הכפתור הנוסף בתפריט מרענן את עמוד הבית בלי PIN. בתוך ההגדרות אפשר לבחור מראה כהה או בהיר; כהה הוא ברירת המחדל.

תחזוקה וחזרה ל־Android

כניסה לניהול ← פתיחת הגדרות Android או יציאה זמנית ← אימות PIN נוסף. הישאר ליד הטאבלט בזמן התחזוקה; במצב זה יש גישה ל־Android. פתיחה מחדש של Kiosk או אתחול מחזירים את הנעילה. ביטול ניהול קבוע זמין בנפרד, עם PIN ואישור נוסף.

בדיקה לפני שימוש קבוע

  1. אתחל את הטאבלט ובדוק שהמסך שבחרת עולה ללא בקשת בחירת מסך בית.
  2. נסה Home, חזרה, יישומים אחרונים ומשיכה מלמעלה. ודא שאין גישה לשאר Android.
  3. פתח ⋮: לפני PIN אין גישה להגדרות, ו־PIN שגוי אינו פותח אותן.
  4. במצב אתר בדוק את כל הפעולות שאתה צריך, ניתוק וחיבור Wi-Fi ואתחול. הורדות, העלאת קבצים, מצלמה, מיקרופון, חלונות קופצים וקישורים לאפליקציות חיצוניות חסומים.
  5. בדוק כניסה לתחזוקה וחזרה לקיוסק, ושמור את ה־PIN לפני מסירת הטאבלט לשימוש אחרים.

האפליקציה עולה לאחר הדלקת הטאבלט; היא אינה יכולה להדליק פיזית מכשיר כבוי. כפתורי חומרה ו־Recovery אינם ניתנים לחסימה מלאה באפליקציה רגילה. במקרה של אובדן PIN עלול להידרש איפוס שמוחק נתונים.
