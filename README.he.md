# Kiosk for Samsung Galaxy Tab S6 Lite

[English](README.md) · רישיון [MIT](LICENSE), זכויות יוצרים © 2026 VXU LABS.

גרסה 1.2.0 מוסיפה תפריט בלחיצה רגילה על ⋮: ריענון עמוד הבית וכניסה להגדרות עם PIN. הממשק החדש כהה כברירת מחדל, עם בחירת מצב בהיר בהגדרות ושדות PIN בולטים. קיימת בחירת עברית או אנגלית בהגדרה הראשונית ובניהול. בניהול, השינוי נכנס לתוקף בעת השמירה. הודעת מצב התצוגה הוסרה מהמסך הציבורי; מצב הנעילה המדויק מופיע רק לאחר PIN. הטקסט שהזנת וכתובת האתר אינם מתורגמים או נמחקים.

לעדכון: התקן את ה־APK החדש מעל הקיים, בלי להסיר את האפליקציה. ה־PIN וההגדרות נשמרים.

אפליקציית Android עצמאית, בעברית, עם שני מצבי מסך: ממשק פנימי (כותרת, הודעה, שעון ותאריך) או אתר HTTPS במסך מלא. האתר, התוכן והמצב ניתנים לשינוי רק אחרי PIN. זו אינה אפליקציה לפתיחת יישום Android אחר.

## קבצים להתקנה

- `dist/Kiosk-1.2.0.apk` — APK חתום להתקנה ישירה, Android 9 ומעלה, ללא תלות בסוג המעבד. דגמי Tab S6 Lite מתאימים לטווח גרסאות זה.
- `dist/Kiosk-Windows-Setup-1.2.0.zip` — APK, כלי ADB רשמיים, סקריפט התקנה והוראות. חלץ את כל ה־ZIP לפני שימוש.
- `dist/SHA256SUMS.txt` — גיבוב לזיהוי ה־APK שנבנה.

התקנת ה־APK בלבד מאפשרת תצוגה והגדרות, אך **לא חוסמת את Android**. לשם כך יש להקצות לאפליקציה Device Owner פעם אחת.

## התקנה והקצאת Device Owner

1. גבה את הטאבלט. אין צורך לבצע איפוס אוטומטית: אפשר לנסות קודם על מכשיר ללא חשבונות, משתמשים נוספים או ניהול ארגוני. אם Android מסרב, ייתכן שיידרש איפוס מפעל **ידני אחרי גיבוי**. הסקריפט המצורף אינו מאפס דבר.
2. בהגדרה הראשונית של הטאבלט התחבר ל־Wi-Fi, אך דלג על הוספת חשבונות Google ו־Samsung. אל תגדיר נעילת מסך של Android. עדכן מראש את Android ואת רכיב Android System WebView לפי האפשרויות הזמינות במכשיר.
3. פתח **הגדרות ← אודות הטאבלט ← פרטי תוכנה**, הקש שבע פעמים על **מספר גרסת Build**. תחת **אפשרויות למפתחים**, הפעל **ניפוי באגים ב־USB**. מיקום הכיתובים משתנה מעט בין גרסאות One UI.
4. חבר למחשב בכבל נתונים ואשר בטאבלט את הרשאת המחשב. אם המכשיר אינו מזוהה, התקן את דרייבר ה־USB הרשמי של Samsung.
5. חלץ את `Kiosk-Windows-Setup-1.2.0.zip`, הפעל `Install-Kiosk.cmd`, בדוק את דגם המכשיר המוצג והקלד `INSTALL`. אם מדיניות Windows מונעת הרצת PowerShell, השתמש בפקודות הידניות להלן; אין צורך לשנות מדיניות אבטחה במחשב.
6. באפליקציה בחר PIN אישי בן 6–12 ספרות ואמת אותו. **אין PIN מובנה ואין קוד מנהל עוקף.** שמור אותו במקום בטוח.
7. בחר **ממשק פנימי** או **אתר אינטרנט**, והזן את התוכן או כתובת מלאה המתחילה ב־`https://`.
8. ודא שמופיע **Device Owner פעיל**, לחץ **שמירה והפעלת הקיוסק** ואשר. ההפעלה מכבה גם USB debugging. מעתה הבית, היישומים האחרונים, ההתראות, חלונות חופפים והסרת האפליקציה מוגבלים, ומסך הבית של המכשיר הוא הקיוסק.

אפשר לבצע ידנית מתוך תיקיית החבילה:

```powershell
.\platform-tools\adb.exe devices
.\platform-tools\adb.exe install -r .\Kiosk-1.2.0.apk
.\platform-tools\adb.exe shell dpm set-device-owner il.co.kiosk/.KioskAdminReceiver
.\platform-tools\adb.exe shell am start -n il.co.kiosk/.MainActivity
```

אם מופיעה שגיאה `Not allowed to set the device owner`, קרא את ההסבר בפלט. בדוק חשבונות, משתמשים נוספים ו־Device Owner קיים. מכשיר בבעלות ארגון מחייב טיפול של מנהל הארגון. אל תסיק שהנעילה פעילה אם הפקודה נכשלה. אם האפליקציה כבר פתוחה בזמן ההקצאה, סגור ופתח אותה שוב, או היכנס להגדרות עם PIN.

## שימוש וניהול

- **גישה להגדרות:** לחץ על ⋮ בפינה הימנית העליונה, בחר **הגדרות הקיוסק** והזן PIN. הדבר פועל גם במצב אתר ובמסך שגיאת רשת.
- **ריענון:** לחץ על ⋮ ואז **ריענון עמוד הבית**. במצב אתר הפעולה חוזרת לכתובת שהוגדרה, גם לאחר מעבר לעמוד פנימי. אין צורך ב־PIN לריענון.
- **מראה:** בהגדרות המוגנות ב־PIN בחר כהה או בהיר ושמור. ברירת המחדל היא כהה; ההעדפה נשמרת גם אחרי הפעלה מחדש. עיצוב האתר נשאר בשליטת האתר.
- **מצב אתר:** קישורים נשארים ב־WebView. כברירת מחדל ניתן לעבור רק בתוך אותו שם מארח מדויק. אם האתר זקוק לכניסה בדומיין אחר, בטל את הגבלת הדומיין בהגדרות. רק HTTPS מותר; תעודות לא תקינות אינן נעקפות.
- קישורי `intent:`, פתיחת אפליקציות חיצוניות, הורדות, העלאת קבצים, חלונות קופצים, מיקום, מצלמה ומיקרופון חסומים. אתרים שמחייבים יכולות אלה או cookies של צד שלישי לא יתפקדו במלואם. יש לבדוק את האתר המיועד בטאבלט.
- **ממשק פנימי:** אפשר לערוך כותרת, הודעת פתיחה והצגת שעון. התוכן נשמר מקומית ואינו דורש אינטרנט. תאריך ושפת יום השבוע תואמים לשפת האפליקציה.
- **תחזוקה:** מתוך הניהול ניתן לפתוח את הגדרות Android או לצאת זמנית ל־Android, אחרי אימות PIN נוסף. מצב התחזוקה נותן גישה רגילה למכשיר עד לחזרה לקיוסק או אתחול — הישאר לידו. בחזרה לקיוסק הנעילה מופעלת מחדש. אחרי יציאה למסך Android ייתכן שיופיע בורר מסך בית; בחר One UI Home לתחזוקה.
- **שינוי PIN:** דורש גם את ה־PIN הנוכחי. אחרי חמישה ניסיונות שגויים ננעל האימות ל־30 שניות; השהיות נוספות גדלות עד 15 דקות ונשמרות גם בסגירת האפליקציה.
- **ביטול קבוע:** ניהול ← ביטול קבוע של ניהול הקיוסק ← PIN ← אישור. רק אז ניתן להסיר את האפליקציה כרגיל. חזרה ל־Device Owner מחייבת שוב הקצאה מהמחשב.
- **עדכון APK:** פתח תחזוקה עם PIN, הפעל שוב USB debugging אם צריך והתקן APK חתום באותו מפתח בעזרת `adb install -r`. לאחר מכן חזור לקיוסק. אין להסיר ולהתקין מחדש כדי לעדכן.

## הפעלה אוטומטית ומגבלות

האפליקציה נבחרת כמסך הבית באמצעות Device Owner ועולה לאחר אתחול. המסך נשאר פעיל כל עוד האפליקציה בחזית. אפליקציה אינה יכולה להדליק פיזית טאבלט כבוי, להבטיח הדלקה כשמחברים מטען, או למנוע אתחול כפוי/Recovery באמצעות כפתורי חומרה. אם יש נעילת Android קיימת, הסר אותה בהגדרה הראשונית כדי שלא תידרש פתיחה אחרי אתחול. אין להחליף הגנות פיזיות על מכשיר ציבורי בנעילת תוכנה.

אם שכחת PIN: אין קוד עוקף ואין איפוס PIN מהאתר או מ־Intent. ייתכן שיידרש איפוס המכשיר ב־Recovery ומחיקת המידע, בכפוף להגנות החשבון של Samsung/Google. שמור PIN וגיבויים אצלך.

## בנייה ובדיקות

הקוד ב־`app/` הוא Java ו־Android SDK, ללא ספריות צד שלישי וללא שירות שרת. ניתן לפתוח את הפרויקט ב־Android Studio (AGP 8.7.3 / Gradle 8.9 / JDK 17 / SDK 35). לחלופין, ב־PowerShell:

```powershell
.\scripts\bootstrap.ps1   # Downloads official JDK/SDK archives and checks their hashes
.\scripts\build.ps1       # Core tests, resources, Java, DEX, APK signing and verification
.\scripts\build.ps1 -TestOnly
```

בבנייה הראשונה נוצר מפתח חתימה פרטי ב־`.signing/`. הוא וסיסמתו אינם נכנסים ל־Git או לחבילת ההתקנה. **גבה את כל תיקיית `.signing` באופן פרטי**, אחרת לא ניתן יהיה להפיץ עדכון שמחליף את ה־APK הזה בלי הסרה. כלים שהורדו נמצאים ב־`.tooling/` ואינם נכנסים ל־Git. לפני הפצה של חבילת כלי Android, יש לעיין בתנאי הרישיון המצורפים לכלים.

בדיקות הליבה מכסות גיבוב PIN, קלט שגוי, האטת ניסיונות ומדיניות כתובות. בדיקת APK מאמתת חתימה ומבנה. ראה `VERIFICATION.md` עבור הבדיקות שהורצו בפועל והבדיקות שנותרו על הטאבלט הפיזי.

מקורות לתכנון: [Android Lock Task](https://developer.android.com/work/dpc/dedicated-devices/lock-task-mode), [Dedicated devices cookbook](https://developer.android.com/work/dpc/dedicated-devices/cookbook), [Samsung USB driver](https://developer.samsung.com/android-usb-driver).
